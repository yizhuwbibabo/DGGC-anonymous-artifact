# Result files

This folder contains the selected CSV files corresponding to the paper tables.

```text
overall.csv       Main table union search performance.
relation_map.csv  Relation-map parameter analysis for tau, gamma, and K.
lambda.csv        Loss parameter lambda analysis.
efficiency.csv    Index construction and search latency.
```

Intermediate sweep logs, checkpoint-level evaluation files, and debug outputs
are not included.

## STALE DATA WARNING

The CSV files in this folder were produced by the pre-revision pipeline
(BERT backbone, cosine-temperature scoring, greedy reranking, no shuffling
phase). The code has since been revised to match the paper's equations
(Eq. 2 multi-positive loss, Eq. 3 squared Wasserstein-2 score, Sec. 3.4
filter-shuffle positives, Eq. 8 Hungarian reranking, RoBERTa backbone).
All result files must be regenerated by re-running the revised pipeline
before any number from them is used. Do not hand-edit these files.
